# ربات تلگرامی فروش آهن‌آلات

ربات ساده‌ای برای ثبت سفارش، نمایش قیمت‌های روزانه و پیگیری وضعیت سفارش، مخصوص کسب‌وکارهای آهن‌آلات.

## امکانات

**برای کاربر:**
- مشاهده دسته‌بندی‌ها و قیمت‌های به‌روز محصولات
- ثبت سفارش با انتخاب محصول، مقدار، آدرس و شماره تماس
- مشاهده لیست سفارش‌ها و وضعیت هرکدام

**برای ادمین (داخل خود تلگرام، بدون نیاز به پنل جدا):**
- افزودن دسته‌بندی و محصول جدید
- تغییر قیمت محصولات (چون قیمت آهن نوسان داره)
- مشاهده سفارش‌های در انتظار و همه سفارش‌ها
- تغییر وضعیت سفارش (در انتظار / تایید شده / آماده‌سازی / ارسال شده / تحویل داده شده / لغو شده) — با یک لمس، دکمه‌ای

وقتی وضعیت سفارش عوض بشه، ربات خودکار به مشتری پیام می‌ده.

## مراحل راه‌اندازی

### ۱. ساخت ربات در تلگرام
1. به [@BotFather](https://t.me/BotFather) پیام بدید و دستور `/newbot` رو بزنید.
2. یک اسم و یک یوزرنیم (باید به `bot` ختم بشه) انتخاب کنید.
3. توکنی که بهتون می‌ده رو کپی کنید (چیزی شبیه `123456:ABC-DEF...`).

### ۲. گرفتن آیدی عددی تلگرام خودتون (برای ادمین)
به ربات [@userinfobot](https://t.me/userinfobot) پیام بدید تا آیدی عددیتون رو بگیرید.

### ۳. نصب و تنظیم
```bash
# نصب پکیج‌ها
pip install -r requirements.txt

# تنظیم توکن به عنوان متغیر محیطی (پیشنهادی)
export BOT_TOKEN="توکن شما اینجا"
```

فایل `config.py` رو باز کنید و:
- اگه از متغیر محیطی استفاده نکردید، `BOT_TOKEN` رو مستقیم جایگزین کنید.
- آیدی عددی خودتون رو داخل لیست `ADMIN_IDS` قرار بدید:
```python
ADMIN_IDS = [123456789]
```

### ۴. اجرا
```bash
python main.py
```

اگه پیام «ربات در حال اجراست...» رو دیدید، یعنی ربات فعاله. برید توی تلگرام و `/start` رو به ربات بزنید.

### ۵. اضافه کردن اولین محصولات (به عنوان ادمین)
1. به ربات دستور `/admin` رو بزنید تا پنل مدیریت باز بشه.
2. روی «➕ افزودن محصول» بزنید و مراحل رو طی کنید (دسته‌بندی → نام محصول → واحد → قیمت).
3. هر وقت قیمت آهن عوض شد، از «✏️ تغییر قیمت» استفاده کنید.

## ساختار پروژه
```
steel_bot/
├── main.py              # نقطه شروع اجرای ربات
├── config.py             # توکن، آیدی ادمین‌ها، تنظیمات
├── database.py            # لایه دیتابیس SQLite
├── keyboards.py            # کیبوردهای شیشه‌ای و معمولی
├── handlers/
│   ├── user.py            # مرور محصولات، ثبت سفارش، وضعیت سفارش
│   └── admin.py            # افزودن محصول، تغییر قیمت، مدیریت سفارش‌ها
├── requirements.txt
└── steel_bot.db           # فایل دیتابیس (خودکار ساخته می‌شه)
```

## دیپلوی روی Render (رایگان، بدون نیاز به سرور شخصی)

Render یه سرویس هاست webhook-مبناست؛ یعنی به‌جای اینکه ربات مدام از تلگرام سوال کنه "پیام جدید داری؟"، تلگرام مستقیم پیام رو به آدرس ربات شما push می‌کنه. کد از قبل برای این حالت آماده شده.

1. یه ریپازیتوری روی GitHub بسازید و محتوای این پوشه رو توش push کنید.
2. به [render.com](https://render.com) برید، ثبت‌نام کنید و ریپازیتوریتون رو وصل کنید (New → Web Service).
3. Render فایل `render.yaml` رو خودش تشخیص می‌ده. اگه نداد، دستی این تنظیمات رو بدید:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python main.py`
   - **Plan:** Free
4. توی بخش Environment Variables دو تا متغیر اضافه کنید:
   - `BOT_TOKEN` → توکنی که از BotFather گرفتید
   - `WEBHOOK_URL` → آدرسی که Render بهتون می‌ده (بعد از اولین دیپلوی مشخص می‌شه، چیزی شبیه `https://steel-bot.onrender.com`)
5. Deploy بزنید. لاگ‌ها رو چک کنید تا خط «ربات با webhook روی پورت... اجرا می‌شه» رو ببینید.
6. به تلگرام برید و `/start` بزنید — باید جواب بده.

⚠️ نکته مهم درباره پلن رایگان Render: بعد از ۱۵ دقیقه بی‌کاری، سرویس می‌خوابه و اولین پیام بعدش ممکنه چند ثانیه طول بکشه تا بیدار بشه (تلگرام خودش پیام رو دوباره می‌فرسته، پس چیزی گم نمی‌شه، فقط یه تاخیر کوتاه داره). اگه نیاز به پاسخ آنی و بدون وقفه دارید، پلن پولی Render یا یه VPS با حالت polling گزینه بهتریه.

## اجرای مداوم روی سرور (اختیاری، حالت polling)
برای اینکه ربات همیشه روشن بمونه، می‌تونید از `systemd`، `screen`، `tmux` یا `pm2` (با wrapper) استفاده کنید، یا روی یک VPS با دستور زیر در پس‌زمینه اجراش کنید:
```bash
nohup python main.py &
```

## نکات مهم
- توکن ربات رو هیچ‌وقت جایی عمومی (مثل گیت‌هاب عمومی) قرار ندید — روی Render توی Environment Variables بذاریدش، نه توی کد.
- ⚠️ روی پلن رایگان Render، فایل‌سیستم دائمی نیست؛ یعنی با هر دیپلوی جدید، فایل `steel_bot.db` (و در نتیجه محصولات و سفارش‌هایی که ثبت کردید) پاک می‌شه. برای دائمی موندن داده‌ها یکی از این کارها رو بکنید:
  - از یه **Render Disk** (پرسیستنت استوریج، پولی) استفاده کنید
  - یا دیتابیس رو به یه سرویس خارجی مثل PostgreSQL رایگان (مثلاً Supabase یا Neon) مهاجرت بدید — اگه بخواید کمک می‌کنم این تغییر رو انجام بدیم.
- این نسخه پرداخت آنلاین نداره — سفارش ثبت می‌شه و پرداخت/تسویه به‌صورت جدا (نقدی، کارت‌به‌کارت و...) با مشتری هماهنگ می‌شه. اگه بعداً خواستید درگاه پرداخت (زرین‌پال و...) اضافه کنید، بگید کمکتون می‌کنم.
